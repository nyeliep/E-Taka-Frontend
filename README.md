# E-Taka - Frontend

This frontend application powers the E-Taka project, an e-waste management platform dedicated to addressing the growing concern of electronic waste disposal and promoting sustainable recycling practices. The frontend provides an administrative dashboard that enables administrators to monitor, manage, and oversee e-waste disposal activities and platform operations.

## Overview

E-Taka is an innovative e-waste management platform that provides individuals with a convenient and eco-friendly way to dispose of their electronic waste. The platform allows users to request e-waste collection from recycling companies for a fee while also providing access to refurbished electronics.

This repository contains the frontend administrative dashboard built with JavaScript. The dashboard provides administrators with a centralized interface for monitoring and managing the platform. It communicates with the E-Taka backend APIs to retrieve and manage user information, e-waste disposal requests, collection activities, recycling operations, and other platform data.

## Features

* Administrative dashboard for monitoring E-Taka platform activities.
* Overview of e-waste disposal and collection activities.
* Management and monitoring of user accounts.
* Management and tracking of e-waste collection requests.
* Monitoring of recycling and disposal activities.
* Access to information related to recycling companies.
* Management and monitoring of refurbished electronics.
* Data visualization and summaries to support administrative decision-making.
* Integration with backend APIs for retrieving and managing platform data.
* Secure interface for authorized administrators.

## Getting Started

### Prerequisites

Before you begin, ensure you have met the following requirements:

* Node.js: Install Node.js to run the frontend application.
* NPM: NPM is required to install and manage the project's dependencies.
* E-Taka Backend: Ensure that the E-Taka backend is configured and running so that the dashboard can communicate with the required APIs.

### Installation

### Step 1: Clone the repository

```sh
git clone https://github.com/akirachix/LogicSpires-Frontend.git
```

### Step 2: Navigate to the project directory

```sh
cd LogicSpires
```

### Step 3: Install the dependencies

```sh
npm install
```

### Step 4: Run the application

```sh
npm run start
```

The E-Taka administrative dashboard should now be running locally and can be accessed through the development server.
